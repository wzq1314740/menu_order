# 桂亭 · 局域网点餐系统

服务运行在办公室的 Windows 电脑上。同一局域网内的设备用浏览器访问即可：

| 用途 | 地址 | 谁用 | 是否需要登录 |
| --- | --- | --- | --- |
| 点餐 | `http://办公室电脑IP:8080/` | 包厢 iPad、服务员手机 | 不需要 |
| 订单看板 | `http://办公室电脑IP:8080/orders.html` | 前台电脑、经理手机等 | 员工口令或管理口令 |
| 菜单后台 | `http://办公室电脑IP:8080/admin.html` | 店长 | 管理口令 |

## 一、首次部署（办公室电脑）

1. 安装 Python 3：到 <https://www.python.org/downloads/windows/> 下载安装，安装界面**务必勾选 “Add python.exe to PATH”**。
2. 把整个 `粤菜点餐` 文件夹拷到办公室电脑，例如 `D:\粤菜点餐`。
3. 右键 `install.bat`，选择“**以管理员身份运行**”，按提示设置两个口令：
   - 员工口令：查看订单、确认和完成订单。
   - 管理口令：在员工权限之外，还可以修改菜单、桌号和口令。
4. 脚本会自动完成以下设置，并在窗口里显示访问地址：
   - 在 Windows 防火墙放行 8080 端口。
   - 设置开机后自动在后台运行（不弹窗口）。
   - 立即在后台启动服务。

### 还需要手动设置的三件事

1. **固定 IP**：在路由器管理页里给办公室电脑做“DHCP 地址保留 / 静态分配”。IP 变化后，iPad 上保存的地址就会失效。
2. **不睡眠**：Windows 设置 → 系统 → 电源 → “睡眠”改为“从不”。电脑睡眠后无法点餐。
3. **同一网段**：办公室电脑和前厅 WiFi 必须在同一个局域网里。如果前厅用的是隔离的访客 WiFi，iPad 会访问不到办公室电脑，需要让网管打通或改用同一个网络。

## 二、日常使用

- **包厢 iPad / 服务员手机**：打开点餐地址，第一次选择包厢或桌号（之后会记住），选菜后在“确认清单”里点“提交给前台”。需要加菜时继续选菜再提交即可。
  - 建议在 Safari 里“添加到主屏幕”，像 App 一样全屏打开。
  - 在后台「门店设置」里可以复制每个桌号的专属链接（形如 `/?table=V01`），打开后自动选好桌号，可以做成二维码贴在桌上。
- **订单看板**：登录后保持页面打开。第一次请点右上角“开启提醒”，之后有新单会响铃，卡片会闪烁高亮。
  - 状态流转：新单 → 确认 → 完成；也可以取消，取消后可以恢复。
  - “按桌汇总”会把同一桌的多次加菜合并显示。
  - 每张单可以单独打印。
  - 多台设备同时打开时，任何一台改了状态，其他设备 3 秒内同步。
- **菜单后台**：修改后点“保存”立即生效，点餐页重新打开或刷新后显示新菜单。
  - 每次保存前会自动备份上一版（保留最近 30 份），在「备份与恢复」里可以找回。
  - 两个人同时修改时，后保存的人会收到提示，需要刷新后再改，不会互相覆盖。
  - 门店名称、包厢和桌号、口令都在「门店设置」里修改。

## 三、文件说明

| 文件 / 文件夹 | 说明 |
| --- | --- |
| `server.py` | 服务程序（只用 Python 标准库，不需要安装其他依赖） |
| `install.bat` / `uninstall.bat` | 安装 / 卸载（防火墙规则和开机自启），需要管理员身份运行 |
| `start.bat` | 在前台窗口运行服务，用于排查问题；关闭窗口即停止 |
| `config.json` | 端口和口令（口令只保存哈希值），首次运行时生成 |
| `data/menu.json` | 当前菜单 |
| `data/orders/日期.json` | 每天的订单 |
| `data/backup/` | 菜单自动备份 |
| `data/server.log` | 运行日志 |
| `images/uploads/` | 后台上传的菜品图片 |
| `menu-data.backup.js` | 改造前的原始菜单文件，可在后台「导入」恢复 |
| `_unused/` | 没有被使用的旧图片，确认不需要后可以删除 |

**备份建议**：定期复制 `data` 文件夹和 `images` 文件夹即可完整备份菜单和订单。

## 四、常见问题

**iPad 打不开点餐页**
1. 在办公室电脑上用浏览器打开 `http://127.0.0.1:8080/`。打不开说明服务没有运行，双击 `start.bat` 查看报错。
2. 本机能打开但 iPad 打不开：检查 iPad 是否连的是同一个网络、IP 是否变了、是否以管理员身份运行过 `install.bat`（防火墙）。

**忘记口令**
在办公室电脑上打开命令行，进入程序文件夹后运行 `python server.py --setup` 重新设置。

**提示找不到 Python，或者运行 python 后打开了微软商店**
重新安装 Python 并勾选 “Add python.exe to PATH”；或在 Windows 设置 → 应用 → 高级应用设置 → 应用执行别名 里关闭 “python.exe” 的商店别名。

**修改端口**
编辑 `config.json` 里的 `"port"`，然后重新以管理员身份运行 `install.bat`（会更新防火墙规则），再重启电脑。

**停止服务**
重启电脑前先运行 `uninstall.bat` 取消开机自启；或在任务管理器里结束 `pythonw.exe`。
